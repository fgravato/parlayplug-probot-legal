Privacy Policy — ParlayPlug-Probot

Last updated: September 11, 2026

ParlayPlug-Probot ("the bot") is a Discord bot providing moderation, welcome messages, and utility commands for the servers it is added to. This policy explains what data the bot accesses and how it is used.

Data the bot accesses

  • Server member information (via the Server Members Intent) — used to detect when a member joins a server so the bot can send a welcome message.
  • Message content (via the Message Content Intent) — used only to detect and parse bot commands (e.g. !ping) that begin with the bot's command prefix. Messages that are not commands are not processed or stored.

Data storage

The bot does not store message content, member lists, or personal data in any external database. Any configuration data (such as server-specific settings) is stored only as needed to operate the bot within that server.

Data sharing

The bot does not sell, share, or transmit any collected data to third parties. Data is used solely to provide the bot's functionality within Discord.

Data retention

The bot does not retain message content or member data beyond what is required to process an event in real time.

Your rights

Server administrators may remove the bot from their server at any time, which immediately stops all data access. Individual users may contact a server's administrators to request removal of any bot-related configuration data.

Contact

Questions about this policy can be sent to frankie.gravato@gmail.com.

This policy applies only to ParlayPlug-Probot and its use of the Discord API.
