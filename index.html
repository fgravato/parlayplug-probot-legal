Privacy Policy — ParlayPlug-Probot

Last updated: October 27, 2026

ParlayPlug-Probot ("the bot") is a Discord bot that welcomes new members of The Parlay Plug server and asks them to acknowledge the server rules. It also provides a /ping slash command. This policy explains what data the bot accesses and how it is used.

Data the bot accesses

  • Server member information (via the Server Members Intent) — when someone joins the server, Discord sends the bot a member-join event containing the member's Discord user ID, username, and membership details. The bot uses the user ID to mention the new member in a rules-acknowledgment prompt and to verify that only that member can click the prompt's button before it posts the full welcome message. This is the only privileged intent the bot uses.
  • Interactions — when a member clicks the rules button or runs /ping, Discord sends the bot that interaction, including the user ID.

The bot does not read message content, presence or status, or direct messages.

Data storage

The bot has no database and does not store message content, member lists, or personal data. Member Discord user IDs appear only in the bot's operational logs, which are used for troubleshooting and contain no usernames or message content.

Data sharing

The bot does not sell, share, or transmit any collected data to third parties. Data is used solely to provide the bot's functionality within Discord.

Data retention

Operational logs are rotated daily and deleted after 7 days. The bot retains no other member data beyond what is needed to process an event in real time.

Your rights

Server administrators may remove the bot from their server at any time, which immediately stops all data access. Individual users may contact a server's administrators to request removal of any bot-related configuration data.

This policy applies only to ParlayPlug-Probot and its use of the Discord API.
