Privacy Policy — Bankroll Bot

Last updated: September 11, 2026

Bankroll Bot ("the bot") is a Discord bot that calculates betting unit sizes, Kelly Criterion bet sizing, expected value, parlay payouts, hedge amounts, and odds conversions from numbers a user provides in a command. This policy explains what data the bot accesses and shares.

Data the bot accesses

  • Message content (via the Message Content Intent) — used only to parse command text a user types, whether as a slash command or a !-prefixed command (e.g. !br1000, !kelly, !ping). The bot does not read, log, or act on any message that is not a recognized command.

Data storage

The bot does not store any data. Every calculation is performed in memory from the numbers included in the command and the result is returned immediately — nothing about the command, the user, or the result is saved anywhere.

Data sharing

Since no data is stored, none is shared. Calculation results are visible only to the user who ran the command (or, for legacy ! commands, in the channel where the command was typed).

Your rights

Because the bot retains nothing about you, there is no stored data to access or delete. Server administrators may remove the bot from their server at any time.

This policy applies only to Bankroll Bot and its use of the Discord API.
