Privacy Policy — Bankroll Bot

Last updated: September 11, 2026

Bankroll Bot ("the bot") is a Discord bot that helps users calculate betting unit sizes and manage a betting bankroll using commands they run themselves. This policy explains what data the bot accesses, stores, and shares.

Data the bot accesses

  • Message content (via the Message Content Intent) — used only to parse command text a user types, whether as a slash command or a !-prefixed command (e.g. !bankroll, !kelly, !ping). The bot does not read, log, or act on any message that is not a recognized command.

Data storage

When a user runs a bankroll command, the bot stores the values that user submits — their Discord user ID, entered bankroll amount, selected risk profile, and calculated unit size, with a timestamp — in a local data file operated by the bot's administrator. No raw message text or content from other users' messages is stored.

Data sharing

The bot does not sell or share stored data with any third party. Data is used only to let a user track their own bankroll history over time through the bot's commands, and is not visible to other users or server moderators beyond what the bot's commands display to the requesting user.

Data retention

Bankroll history is retained so a user can view their own past entries. A user can request deletion of their stored history at any time by contacting the operator below.

Your rights

You may request access to, or deletion of, your stored bankroll history at any time by emailing the contact below. Server administrators may remove the bot from their server at any time, which stops further data collection.

Contact

This policy applies only to Bankroll Bot and its use of the Discord API.
