Privacy Policy — PhantomChaser

Last updated: September 11, 2026

PhantomChaser ("the bot") is a Discord bot that detects accounts impersonating a server's admins or other protected users. This policy explains what data the bot accesses, stores, and shares.

Data the bot accesses

  • Server member information (via the Server Members Intent) — used to build a profile fingerprint (username, display name, avatar) for members when they join or are scanned, so new accounts can be compared against protected users for impersonation attempts.
  • Message metadata (via the Message Content Intent) — used to run moderator commands (prefixed with !, e.g. !status, !protected, !config) and to check basic message timing signals (such as whether a message timestamp appears altered). The bot does not read, log, or act on the text of ordinary messages.

Data storage

The bot stores the following in a local database operated by the bot's administrator (not shared with any third party as a data set). Username, display name, and avatar hash fields are encrypted at rest.

  • User ID, username, display name, and a perceptual hash of the profile avatar — for protected users and, for comparison purposes, for other members of servers the bot protects.
  • Account creation date and server join date.
  • Records of detected impersonation matches (flags), for review by server moderators.

The bot does not store the content of regular chat messages.

Third-party processing

For borderline impersonation cases, the bot may send a sanitized username and display name (never message content or other personal data) to a third-party AI model to help assess whether a name is a deliberate lookalike. This is used only to compute a risk score and is not used to build user profiles beyond that single check.

Data sharing

The bot does not sell member data. Data is used only to operate impersonation detection within the servers where the bot is installed, and is visible only to that server's moderators through the bot's commands.

Data retention

Member fingerprint records and resolved impersonation flags are automatically deleted after 30 days. Protected-user (admin) fingerprints are kept only as long as needed for active protection and refresh automatically on each scan. A server administrator can request earlier deletion of a server's data by removing the bot and contacting the operator below.

Your rights

Server administrators may remove the bot from their server at any time, which stops further data collection. Individual users may contact a server's administrators, or the bot operator directly, to request review or removal of their stored fingerprint data.
